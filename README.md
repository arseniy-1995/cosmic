# COSMIC

GEANT4-моделирования эксперимента Дейтрон.
Внесена геометрия установки из 2021 и 2023 года, включая сам детектор и систему мечения (магниты D1, D2, D3, QF, QD,
газовые детекторы GEMs и стартовый счетчик). Изначально писалась для космической калибровки детектора.
Позже были добавлены другие генераторы процессов.

1. Космика. Собственный генератор и генератор EcoMug
2. pn-пара из кинематики
3. процесс для LQ-поляриметра для дейтериевой и водородной мишени. Квазиупругое рассеяние ep в модели спектатора
   Процесс ed(сигнал)+ep(фон)
4. Процессы из генератора GENBOSS, в частности сигнальный $ \gamma D = pn $, для анализа фона.
5. pp-пара для калибровки протонной дорожки.
6. Процесс $ \gamma D = pp\pi^- $ также из GENBOSS
7. Процесс с рассеянием электронов в магнитном спектрометре (магните D2) системы мечения. Прохождение электронов черех
   тройку дипольных магнитов (заданы магнитные поля). Учет влияния тормозных фотонов на мишени для генерации электронов
   и расчета их попадания в GEM. Генератор тормозных фотонов. Возможность подключать физику для расчета синхротронного
   излучения.

Реализованы различные варианты триггера для записи в файл как в эксперименте (космика, pn, pp, система мечения).
Поддержка многопоточности и вывод в единый root файл информации с детекторов по завершении симуляции.
